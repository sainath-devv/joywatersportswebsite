# Public Assets Directory

This folder is served at the root URL path (`/`) by Vite. 

To complete your website setup, please upload or replace the following video assets here:

1. **`herovid.mp4`**: The hero landing background video (referenced as `/herovid.mp4`).
2. **`reel1.mp4`**: First reel video card file (referenced as `/reel1.mp4`).
3. **`reel2.mp4`**: Second reel video card file (referenced as `/reel2.mp4`).
4. **`reel3.mp4`**: Third reel video card file (referenced as `/reel3.mp4`).

*Note: For the best performance and quick loading, keep the videos short (e.g., 5-15 seconds) and optimized/compressed for web delivery (H.264 MP4 format).*
